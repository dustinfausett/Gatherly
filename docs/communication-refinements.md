# Invitations, contacts and device refinements

- New invitations expose `short_url` in addition to the existing `url`, `path`, QR and code. Production uses `https://churptree.com/i/XXXXXXXXXX`. Both public website and app deployments serve this route and redirect to the configured `APP_URL` sign-in, preserving the invitation through signup/sign-in. Existing QR/full links and codes keep their expiry, revocation and member-approval rules. Deploy both services from this revision when hosted separately.
- Sharing and SMS compose use the short URL. SMS is plain text: recipient phone software makes the URL clickable; custom link labels are available inside Churp, not SMS. Nest, private and phone message text now links explicit HTTP(S) URLs safely.
- Mobile navigation owns its bottom safe-area inset once. Desktop navigation remains unchanged.
- Compose uses **Send Many Individually**, with newly generated one-to-many bird artwork. The optional Tree/Nest filters intersect the current contact/Birdhouse selection. Only joined Nests and Nests the sender administers expose recipient scopes. Hidden, unjoined Nests do not appear.
- Phone contacts must have an explicit Churp-member link to match a Nest filter. Churp does not infer phone ownership. Server validation checks selected Nest membership at conversation creation, preview, queue, retry and dispatch. The additive `sms_job_context.filter_nest` column preserves the filter across restarts and suppresses a queued recipient who leaves the Nest. Existing source-Nest admin checks, parent protections, consent, mock/live separation and provider configuration are unchanged.
- Add Contact can choose shared Tree members with a Tree filter. Unapproved adult/youth links remain unavailable. Imports can add selected contacts to an existing owned Birdhouse or atomically create a new one. Existing duplicate contacts also enter the selected Birdhouse; unrelated memberships are preserved.
- Device notifications prefer on for each signed-in account/browser. Existing granted permission reconnects automatically; new devices need an explicit browser permission tap. iPhone web push requires installation to the Home Screen. Turning off in settings persists a device/account opt-out; dismissing the initial prompt is separate. Nest mute settings continue to determine recipients. Browser grants cannot be forced by the app.
- Pending parent confirmations and adult-message approvals display an egg on the account avatar and the Family & youth protection menu icon, with a gold glow. Youth waiting for parent confirmation also see this alert in the setup gate. Live refresh clears it when the action is complete. Reduced-motion users receive a static highlight.
- Four original generated transparent PNGs are committed under `public/brand/navigation`, previewed in that directory’s README: leaf, three-bird Members, colorful creation requests, and one-to-many messaging. Existing artwork is reused everywhere else.

Validation covers authenticated/expiring short links, public redirects, Tree isolation, hidden-Nest roster access, atomic Birdhouse imports, filtered SMS dispatch after removal/restart, family alerts, default notification permissions and saved opt-out, plus desktop/iPhone/Android flows and mobile inset geometry. Tests use isolated accounts and mock SMS only.
