# Unknown account portrait

`churp-unknown-crow.png` was generated for Churp's deleted-account identity on November 5, 2026. It is displayed only when the server assigns the system `deleted-crow` portrait to a deleted account. It is not included in `AVATARS`, `BIRDS`, unlock codes, purchases or any user-facing picker. Active profile APIs reject this reserved portrait ID.

The original generated artwork is preserved in the shared generation workspace. This repository copy supplies the same static asset to the web and future native clients.
