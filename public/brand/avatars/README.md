# Churp profile avatars

Twenty free bird portraits share Churp’s rounded, softly shaded bird style. These are profile pictures, separate from the twelve unlockable pets that perch in Tree banners and fly into Nests.

![The twenty Churp bird profile avatars](churp-portraits.png)

The generated PNG is kept intact. `shared/avatars.js` lists stable selection IDs in reading order, and `src/AvatarPortrait.jsx` displays one portrait at a time using SVG viewports. The picker, message avatars, member list and account menu use the same artwork.

Rows: Bluebird / Goldfinch / Pink Blossom / Lavender; Mint / Coral / Cardinal / Robin; Woodland Owl / Snowy Owl / Parrot / Cockatiel; Hummingbird / Blue Jay / Dove / Penguin; Toucan / Lovebird / Sparrow / Budgie.
